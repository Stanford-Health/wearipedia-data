# Getting started with the Oura API

### Overview

The Oura API makes it easy to access data generated by the Oura Ring. To
use the Oura API, you need an Oura account and either a [Personal Access
Token](/personal-access-tokens) or an [API
application](/oauth/applications). This documentation is for the Oura
API V1. [Click here to view documentation for the Oura API
V2,](/v2/docs) which includes additional data types and functionality.
For more information on rate limiting see the V2 documentation
[here](v2/docs#section/Rate-Limit).

### API V1 Removal

The V1 API was removed on January 22nd, 2024. You can find the latest V2
documentation [here](https://cloud.ouraring.com/v2/docs)

## Getting started

### 1. Create an Oura account

If you don't already have one, create an Oura account using the Oura
[iOS](https://apps.apple.com/us/app/oura/id1043837948) or
[Android](https://play.google.com/store/apps/details?id=com.ouraring.oura&hl=en)
application. Use the same account to sign-in to
<https://cloud.ouraring.com>.

### 2a. Create a Personal Access Token

If you only want to access your own data, the easiest option is to
create a personal access token. Learn more from the [Authentication
section](/docs/authentication#personal-access-tokens).

### 2b. Create an API application

If you want to use the Oura API to pull data from multiple users, you'll
need to register a new OAuth2 application under [API
Applications](/oauth/applications). Give your application a name and
website that describes your integration.

A registered OAuth application is assigned a unique Client ID and Client
Secret. The Client Secret should not be shared.

By default, API Applications have a ten user limit. If you want to
release your application to a wider audience, your application needs to
be approved. Once you have finished developing your application, you can
submit it for review from the application's page.
