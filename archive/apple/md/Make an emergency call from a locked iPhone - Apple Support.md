# Make an emergency call from a locked iPhone

Even if an iPhone is locked, you can still make an emergency call and
check for a Medical ID. Medical ID helps first responders access
critical medical information.

## Make an emergency call

1.  Go to the Lock screen, then tap Emergency.

2.  Make a call.

## Check for a Medical ID

If someone needs help and is unresponsive, you can check their iPhone
for a Medical ID. The Medical ID provides information about a person
that might be important in an emergency, like allergies, medical
conditions, and who to contact. Medical IDs can be shared automatically
with first responders during an emergency call.\* Learn more about how
to
<a href="https://support.apple.com/kb/HT207021" class="gb-anchor">set up
a Medical ID in the Health app</a>.

If the iPhone is locked, go to the Lock screen, then tap Emergency \>
Medical ID. If the iPhone is unlocked, open the Health app, then tap the
Medical ID tab.

<div class="note gb-note">

\*Available only in the United States.
