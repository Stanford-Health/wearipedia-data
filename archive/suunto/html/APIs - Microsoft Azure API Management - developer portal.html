APIs

Here you can find the API for connecting to Suunto consumers using the Suunto App. There is a possibility to create a connection which enables person to transfer i.e. training data to your application. Each page has documentation about the calls and possibility to try the API In order to get access to try the API you need to be accepted for Suunto partner program.
